# LANDSCAPE_GO — коротка пам’ятка для пробних ігрових маршрутів

Ця пам’ятка не замінює [повні правила FG-1 та Scoring v0.2](../../SOURCE_DOCUMENTS/LANDSCAPE_GO_COMPLETE_RULES_UK.md).

**Підготовка.** Два гравці використовують спільну матрицю висот H на клітинках N×N (камені розміщують **у клітинках**, а не на перетинах). Чорні починають, komi=0, по одному каменю за хід. Ваги можуть бути додатними, нульовими або від’ємними. Сусідство — лише за сторонами.

**Свободи («дихання»).** Група — камені одного кольору, з’єднані за сторонами. Свобода — суміжна незайнята й незаморожена клітинка. Хід без свободи власної групи **до** зняття каменів суперника заборонено, навіть якщо класичне Го дозволяло б такий захват.

**Захоплення.** Після легального ходу знімають суміжні групи суперника без свобод. Їхні клітинки назавжди **заморожуються**: займати їх або використовувати як свободи більше не можна.

**Пас.** Добровільний пас заборонено. Якщо легальних ходів немає, а суперник має ходи, — вимушений пропуск. Партія закінчується, коли легальних ходів немає в обох.

**Підрахунок.** Живий камінь додає власникові вагу w, зокрема від’ємну. За захоплений камінь ваги w нараховується c(w)=0 при w=0, інакше max(1,w,1−w). Основна різниця V=P_Black−P_White. Офіційний результат U=(V,C,Z,R,L,F) порівнюють лексикографічно зліва направо (визначення компонент — у повних правилах). Лише U=0 означає нічию; V=0 саме собою — ще ні.

**Увага.** FG-1 — не класичне Го. Dynamic Landscape — інша дослідницька модель з іншими ходами/пасом. Для серйозної партії та спірних випадків користуйтеся повними правилами.

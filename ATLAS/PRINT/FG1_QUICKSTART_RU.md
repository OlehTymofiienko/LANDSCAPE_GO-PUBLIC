# LANDSCAPE_GO — короткая памятка для пробных игровых маршрутов

Эта памятка не заменяет полное описание [FG-1 и Scoring v0.2](../../SOURCE_DOCUMENTS/LANDSCAPE_GO_COMPLETE_RULES_RU.md).

**Подготовка.** Два игрока используют общую матрицу высот H на клетках N×N (камни размещаются в клетках, а не на пересечениях). Чёрные начинают, komi=0, по одному камню за ход. Веса: положительные, ноль или отрицательные. Соседи только по сторонам.

**Свободы.** Группа — связные по сторонам камни одного цвета. Свобода — соседняя незанятая и незамороженная клетка. Запрещён ход без свободы собственной группы **до** снятия противника, даже если обычное Го допускало бы такой захват.

**Захват.** После легального хода снимаются соседние группы противника без свобод. Их клетки навсегда **замораживаются**, не могут быть заняты и не служат свободами.

**Пас.** Добровольный пас запрещён; если ходов нет, а у соперника есть — вынужденный пропуск. Конец, когда легальных ходов не осталось у обоих.

**Счёт.** Живой камень даёт владельцу вес w (включая отрицательные). За захват камня с весом w награда c(w)=0 для w=0, иначе max(1,w,1−w). Первичная разность V=P_Black−P_White. Официальный результат U=(V,C,Z,R,L,F) сравнивается лексикографически слева направо (точные определения младших компонентов в полных правилах). Полный ноль U=0 — ничья; только V=0 — ещё не обязательно ничья.

**Предупреждение.** FG-1 не является классическим Го. Dynamic Landscape — отдельная исследовательская модель с другим ходом/пасом. Для серьёзной игры и спорных случаев обязательно открывайте полный документ правил.

# LANDSCAPE_GO — гра FG-1 і два наукові Атласи ландшафтів

**Публічне авторське видання з чистою історією Git · 19 листопада 2026 року · експериментальна v4 (не оголошений стабільний реліз `v4.0.0`).**

Мови: [English](README.md) · [Українська](README_UK.md) · [Русский](README_RU.md).

LANDSCAPE_GO — автономна стратегічна гра, натхненна Го, із **власними правилами FG-1 / Scoring v0.2**. Це **не класичне Го**, не окрема дослідницька модель Dynamic Landscape і не суперник рівня AlphaGo. Камені розміщують **у пронумерованих клітинках**, захоплені клітинки назавжди заморожуються, добровільний пас заборонено. **Первинне V=0 не доводить повного U=0**. Невідомі глобальні мінімаксні значення великих полів залишаються невідомими.

## Як почати гру

1. Установіть Python 3.11+ із Tkinter (для Windows зазвичай входить у Python, у Linux часто потрібен `python3-tk`). Для звичайної гри додаткових бібліотек pip не потрібно.
2. Розпакуйте ZIP в нову теку. Windows: `START_LANDSCAPE_GO_WINDOWS.bat`; Linux/macOS: `python3 LANDSCAPE_GO.py`.
3. Виберіть **English / Українська / Русский**, розмір поля й режим **Original, Dual Priority або Monochrome**. Можна грати з людиною/комп’ютером, скасовувати ходи, зберігати партії та переглядати вбудований Атлас.
4. У рушії вже є фільтри наукових каталогів. Друковані Атласи — **відібрані приклади**, а не всі монохромні матриці дослідження.

## Два Атласи для друку A4

- **Основний:** `ATLAS/PRINT/PRINT_PREVIEW_37_LANDSCAPES.html` — 37 полів від 3×3 до 19×19 та обкладинка, **38 сторінок A4**.
- **Знаковий/монохромний:** `ATLAS/SIGNED_MONO/PRINT_PREVIEW_A4.html` — **18 полів, 18 сторінок A4**.

Відкрийте HTML у браузері, натисніть Ctrl+P, виберіть **A4, книжкова орієнтація, масштаб 100% без підгонки**, вимкніть колонтитули. PDF-макети пройшли перевірку на Windows та Ubuntu; **правовласник повідомив про прийнятні паперові проби**, зокрема 19×19 із мінімальними цифрами ≈7 pt. Докладніше — `ATLAS/PRINT/PRINT_GUIDE_UK.md`.

## Повні правила та науковий статус

**[Повні правила українською](SOURCE_DOCUMENTS/LANDSCAPE_GO_COMPLETE_RULES_UK.md)**, [оригінал російською](SOURCE_DOCUMENTS/LANDSCAPE_GO_COMPLETE_RULES_RU.md). Коротка [пам’ятка українською](ATLAS/PRINT/FG1_QUICKSTART_UK.md) і російською — у `ATLAS/PRINT/`.

У цьому випуску містяться **45 оригінальних ігрових JSON** і два наукові JSON-каталоги Атласів. Приватну Git-історію, дослідницькі ZIP/GZIP та SQLite не включено. Код гри, матриці й усі 55 друкованих таблиць (7797 клітинок) збережено; змінено лише пояснювальні документи та старі службові написи поза матрицями. Перевіряйте склад за `SHA256SUMS.txt`, а SHA-256 самого ZIP — за зовнішнім `DOWNLOAD_SHA256.txt`.

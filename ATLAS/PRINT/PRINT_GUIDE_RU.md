# LANDSCAPE_GO — инструкция печати авторских Атласов

1. Основной Атлас `ATLAS/PRINT/PRINT_PREVIEW_37_LANDSCAPES.html` — **37 полей + титульная страница, 38 листов A4**.
2. Знаковый/монохромный Атлас `ATLAS/SIGNED_MONO/PRINT_PREVIEW_A4.html` — **18 полей, 18 листов A4**.
3. Откройте HTML в браузере, нажмите **Ctrl+P** и выберите **A4, портретная ориентация, 100% без подгонки**, отключив колонтитулы браузера.
4. Камни размещаются **в клетках**, а не на пересечениях. Для 19×19 выбирайте мелкие маркеры, не закрывающие числовые значения (в том числе отрицательные).
5. Полные правила: `SOURCE_DOCUMENTS/LANDSCAPE_GO_COMPLETE_RULES_RU.md`; украинский перевод: `SOURCE_DOCUMENTS/LANDSCAPE_GO_COMPLETE_RULES_UK.md`. Действуют **FG-1 / Scoring v0.2**, а не классические правила Го.
6. Электронная проверка печатных HTML выполнена на Windows и Ubuntu: **38/38 + 18/18 A4**, без выхода текста за лист, минимальный шрифт **около 7 pt**. Владелец сообщил, что распечатки на бумаге проверены и согласованы; независимое заключение типографии не прилагается.

Согласно действующему авторскому дополнению `ADDITIONAL_PERMISSION_RU.md` допускается **бесплатная раздача неизменённых оригинальных распечаток** и полного неизменённого утверждённого комплекта при сохранении правовых уведомлений. Продажа и публичная переделка охраняемых авторских материалов дополнением не разрешены. Официальный `LICENSE` PolyForm Strict остаётся неизменным.

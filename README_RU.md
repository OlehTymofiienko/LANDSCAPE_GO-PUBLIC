# LANDSCAPE_GO — игра FG-1 и два научных Атласа ландшафтов

**Публичная авторская версия с чистой Git-историей · 19 ноября 2026 года · экспериментальная v4 (не объявленная стабильной `v4.0.0`).**

Языки: [English](README.md) · [Українська](README_UK.md) · [Русский](README_RU.md).

LANDSCAPE_GO — автономная стратегия по мотивам Го с **собственными правилами FG-1 / Scoring v0.2**. Это **не классическое Го**, не отдельная исследовательская Dynamic Landscape и не компьютерный соперник уровня AlphaGo. Камни ставят **в пронумерованные клетки**, захваченные клетки навсегда замораживаются, добровольный пас запрещён. **Первичное V=0 не доказывает полного U=0**. Неизвестный глобальный минимакс больших полей остаётся неизвестным.

## Как играть

1. Нужен Python 3.11+ с Tkinter (в Windows обычно входит в установку Python; для Linux часто требуется `python3-tk`). Обычная игра не требует отдельных pip-пакетов.
2. Распакуйте архив в новую папку. Windows: `START_LANDSCAPE_GO_WINDOWS.bat`; Linux/macOS: `python3 LANDSCAPE_GO.py`.
3. Выберите English, Українська или Русский, размер поля и один из режимов: **Original, Dual Priority, Monochrome**. Доступны игра против человека/компьютера, отмена хода, сохранение и загрузка партий, встроенный Атлас.
4. Фильтры научных каталогов встроены в игру. Печатные Атласы — **отобранные ландшафты**, а не все исследованные матрицы.

## Оба Атласа для печати A4

- **Основной:** `ATLAS/PRINT/PRINT_PREVIEW_37_LANDSCAPES.html` — 37 полей от 3×3 до 19×19 + титул, всего 38 страниц A4.
- **Знаковый/монохромный:** `ATLAS/SIGNED_MONO/PRINT_PREVIEW_A4.html` — 18 полей, всего 18 страниц A4.

Откройте HTML в браузере, нажмите Ctrl+P, укажите A4, вертикальный формат, 100% без подгонки, отключите колонтитулы. PDF-макеты прошли проверку на Windows и Ubuntu; **владелец подтвердил пробную бумажную печать**, включая мелкие цифры 19×19 (≈7 pt). См. `ATLAS/PRINT/PRINT_GUIDE_RU.md` и украинскую инструкцию `PRINT_GUIDE_UK.md`.

## Правила и научный статус

Полные исходные правила: `SOURCE_DOCUMENTS/LANDSCAPE_GO_COMPLETE_RULES_RU.md`; полный украинский перевод: `SOURCE_DOCUMENTS/LANDSCAPE_GO_COMPLETE_RULES_UK.md`; короткие памятки — в `ATLAS/PRINT/`. Не смешивать FG-1, Dynamic Landscape и классическое Го, а V=0 — с полным U=0.

Включены **45 оригинальных DATA JSON** и два научных JSON-каталога Атласов. Не включены приватная история Git, исследовательские ZIP/GZIP и SQLite. Исходный игровой код, матрицы каталогов и 55 печатных таблиц (7797 клеток) сохранены; изменены только публичные пояснения и старые служебные надписи вне таблиц. Для точной проверки используйте `SHA256SUMS.txt`, внешний SHA ZIP — в `DOWNLOAD_SHA256.txt` рядом с архивом.
